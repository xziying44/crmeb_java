# CRMEB 二次开发模块计划

> 基于需求分析，以下为需要开发的功能模块清单

---

## 一、角色体系扩展

| 角色 | 说明 | 优先级 |
|-----|------|--------|
| 老板 | 数据看板、全局统计报表 | 中 |
| 财务 | 对账管理、财务报表、结算审批 | 高 |
| 仓库管理员 | 进销存操作权限、库存管理 | 高 |
| 业务员 | 创建经销商、查看下级销售额、业绩提成 | 高 |
| 一级经销商 | 专属价格、返点、小程序下单 | 高 |
| 散客 | 已有，无需开发 | - |

---

## 二、核心功能模块

### 模块1: 进销存系统 🔴 高优先级

```
├── 供应商管理（供应商信息、分类）
├── 采购管理（采购单、采购入库、采购退货）
├── 库存管理（入库单、出库单、库存盘点、调拨）
├── 仓库管理（多仓库、库位）
└── 库存报表（进出库流水、盘点差异）
```
**预估工期**: 3-4周

---

### 模块2: 业务员管理 🔴 高优先级

```
├── 业务员账号（注册、审核、门店绑定）
├── 经销商创建（业务员创建下级经销商）
├── 业绩统计（下级销售额、排行榜、月报）
└── 返点管理（返点规则、计算、发放）
```
**预估工期**: 2-3周

---

### 模块3: 分级定价体系 🔴 高优先级

```
├── 客户等级（散客、一级经销商等）
├── 商品多级价格（不同等级不同价格）
├── 阶梯价格（数量越多价格越低）
└── 客户专属价（单独设置特定客户价格）
```
**预估工期**: 1-2周

---

### 模块4: 促销活动扩展 🟡 中优先级

```
├── 满减活动（满100减20、阶梯满减）
├── 买赠活动（10送3、买A送B）
└── 代金券（固定面额、可转赠）
```
**预估工期**: 1周

---

### 模块5: 返利与积分扩展 🟡 中优先级

```
├── 客户返利（按订单/按月计算返利）
├── 按月返点（月度结算、自动发放）
├── 积分兑换（积分商城、兑换商品）
└── 积分折现（积分兑换余额）
```
**预估工期**: 1-2周

---

### 模块6: 财务管理 🟡 中优先级

```
├── 对账管理（支付对账、退款对账）
├── 财务报表（收入、支出、利润）
└── 结算管理（经销商结算、业务员结算）
```
**预估工期**: 1-2周

---

## 三、开发阶段规划

| 阶段 | 周期 | 内容 |
|-----|------|------|
| **第一阶段** | 2-3周 | 角色权限 + 业务员模块 |
| **第二阶段** | 3-4周 | 进销存系统 |
| **第三阶段** | 2周 | 分级定价体系 |
| **第四阶段** | 1周 | 促销活动扩展 |
| **第五阶段** | 2周 | 返利积分扩展 |
| **第六阶段** | 1-2周 | 财务管理 |

**总计**: 约 12-16 周（3-4个月）

---

## 四、技术要点

1. **数据库**: 新增约 15 张表（业务员、供应商、采购单、库存单、多级价格等）
2. **权限**: 基于现有 RBAC 扩展，增加数据权限隔离
3. **库存同步**: 进销存与商品库存字段联动，注意并发控制
4. **价格计算**: 优先级：专属价 > 等级价 > 促销价 > 原价
